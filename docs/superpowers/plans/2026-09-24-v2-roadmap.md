# Mission Control 2.0 — roadmap

The quiet design replaces the current UI **in place** on `main`: no `/v2`, no final cutover. Each phase is its own plan under `docs/superpowers/plans/`, written when the phase before it lands. Decisions the plans implement: `docs/decisions/system-chat.md`, `docs/new-design-port-status.md`, `docs/design/chat-agent-cards/DECISION.md`, the studies in `docs/design/quiet-chat/terminals-*.html`.

**Who builds what:** server and data work runs as mc-dispatch cockpit jobs (the cockpit answers on 7777). UI work is done in the planning session and shown in the running app. Every task in every plan is tagged `[worker]` or `[here]`.

**Restarts:** the app keeps live terminals only in memory. Any task that changes `server/` needs a restart of the app on 7777, which ends those sessions. Each plan lists its restart points; restarts happen when the user says so.
