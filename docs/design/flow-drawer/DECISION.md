# Decision: Session flow drawer

**Chosen:** Variant D, a full-width canvas panel above the chat or terminal that draws the session's real workflow run.

**Why:** Flows are now real, executable Studio workflow runs that can be large: parallel paths, retry loops, fix loops. D gives every step room for its engine, try number and time, draws loops as arcs and paths as labelled bands, and zooms. The user picked it over E (side dock) and F (compact lanes).

**Screens:** `d-terminal.html` (running, big change proposed), `d-draft.html` (waiting for first approval), `d-auto.html` (approval turned off), `d-none.html` (quick work, no flow). Generated by `gen_flow_v2.py`; styles in `flow-v2.css` + `drawer.css`.

**Real files to touch:** `server/views/shell.ts:69-75` (`#flow` markup), `client/flow-graph.ts` (renderer), `client/shell-activity.ts` (data + refresh), `client/awareness.ts` (`flowSteps`/`flowColumns` go away), `public/quiet.css:201-208,389-413` (drawer + graph styles).

**Implementation notes:**
- Panel: raised card, `calc(100% - 56px)` wide, `--r-lg` corners, 14px/16px padding. It pushes the terminal down; the graph area scrolls and zooms inside it.
- Header row: task title (14px/500) with a meta line under it (11.5px muted): saved workflow name or "New flow drafted by …", which AI picked it and where (chat / terminal), and how the current version was approved (drawer click, conversation, or auto because approval is off). Right side: status pills (`.pill-state` running / done / queued), then Pause, Open in Studio (or Edit in Studio for drafts), close.
- Banner under the header, only when something needs the user or just happened:
  - Draft waiting: accent banner, "Reject" + primary "Approve and run".
  - Big change proposed mid-run: accent banner, "See change" / "Keep v1" / primary "Approve v2". The proposed step is drawn in the graph as a dashed accent ghost with a `+` mark.
  - Approval off: green notice "v2 applied automatically …" with "See change" / "Turn approval on".
- Steps: 160×52, `#f6f7fb`, 1px `--line`, 12px radius. Left: engine logo (or a glyph for join / your review). Title 12.5px/500, detail 10.5px muted (`Try 2 · 3m 40s`, `3 sub-agents · 5m`). Right: status mark (done check on `#dcece1`, running pulse on `#e6def7`, failed `!` on `#f5dde3`, pending hollow ring). Running step keeps the existing accent border + `flow-pulse`. Conditional steps (only reached on a fail edge) are dashed at 62% opacity.
- Arrows: done `#6f9c7e`, running accent with the moving dash, waiting `#b9c2d3`, retry / fail loops `#c9798b` dashed with a small label ("tests failed · retried" once taken, "if tests fail" while only planned).
- Parallel paths: a shaded band (`#e2e6f080`, `--r-lg`) behind each path, labelled "api path · `flow/csv-export-api`" with the worktree branch in mono accent.
- Quick work with no flow: the same card, short: title + "Quick work · <AI> decided this does not need a flow", then the agents as a plain list (mark, engine logo, title, status · time).
- Sub-agents inside a step appear in the step's detail ("3 sub-agents"), never as their own boxes.
- The sample flow skips the plan-check step to fit the mockup; real flows keep Studio's safety rules (plan verified before implementation, cross-family review after it).

**Rejected:** A/B/C (first round, built around the old synthesized 3-box flow); E, side dock (terminal ~30% narrower, clashes with the Agents drawer); F, compact lanes (no times or details without hovering).
